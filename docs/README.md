# 📚 Playlist Studio Documentation

## Playlist Studio

**Playlist Studio** is a Windows IPTV workspace for managing, editing, testing and playing IPTV playlists and services.

### Supported IPTV Sources

- **M3U / M3U8** playlists
- **Xtream Codes**
- **Stalker Portal / MAC**

### Main Features

- IPTV playlist import and editing
- Channel and category management
- Stream URL management and testing
- Built-in IPTV playback
- EPG support
- Channel logo and metadata management
- Duplicate channel and stream detection
- Multi-channel and multi-category selection
- Save / Save As
- Multiple interface themes
- Windows portable application
- GitHub integration
