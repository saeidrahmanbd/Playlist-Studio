# 🖥️ Playlist Studio 5.0

**Windows IPTV Playlist Manager, Editor & Player**

Playlist Studio 5.0 is a Windows IPTV application for managing, editing, testing and playing M3U/M3U8 playlists, Xtream Codes services and Stalker Portal/MAC services.

## Supported IPTV Sources

| Source | Support |
|---|---|
| M3U | ✅ |
| M3U8 | ✅ |
| Xtream Codes | ✅ |
| Stalker Portal / MAC | ✅ |
| EPG | ✅ |
| Built-in Playback | ✅ |

## Key Features

- IPTV playlist editing and organization
- Channel and category management
- Channel name, ID, number and metadata editing
- Logo management
- Stream URL management
- Built-in playback
- Stream scanning and status checking
- EPG support
- Duplicate channel and stream detection
- Multi-channel selection
- Multi-category selection
- Import playlists from files or URLs
- Save / Save As
- Multiple interface themes
- Portable Windows application
- GitHub integration

## Build Instructions

1. Download the Windows Build Kit.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Run **BUILD-Windows.cmd**.
5. Wait for the build to finish.
6. The generated application is available in the main folder and **dist**.
7. Run **Playlist-Studio-5.0.exe**.

See **Readme.txt** included in the build kit for detailed instructions.
