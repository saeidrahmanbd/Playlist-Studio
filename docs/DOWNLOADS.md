# Playlist Studio — Downloads

## Recommended: just use the app

**[Download Playlist Studio 5.0 for Windows](https://github.com/saeidrahmanbd/Playlist-Studio/releases/download/v5.0.0/Playlist-Studio-5.0.exe)**

1. Click the download link.
2. When the download finishes, open `Playlist-Studio-5.0.exe`.
3. Open your playlist and start working.

No traditional installation is needed. You do not need to install Python or VLC separately. On the first launch, wait a few seconds for the app to start.

**Windows SmartScreen?** First make sure the file came from this official release. If it did, select **More info → Run anyway**.

## Build Kit — only if you want to build the app yourself

[Download the Windows Build Kit ZIP](https://github.com/saeidrahmanbd/Playlist-Studio/releases/download/v5.0.0/Playlist-Studio-5_0-Windows-Build-Kit-Debug22.zip)

This is for developers or advanced users. It requires Windows 10/11 64-bit, Python 3.12+ with the `py` launcher and Tkinter, plus an internet connection.

1. Extract the ZIP to a folder.
2. Double-click `BUILD-WINDOWS.cmd`.
3. Wait for **BUILD COMPLETE**.
4. The EXE and ZIP will be created in the kit folder.

If you only want to use Playlist Studio, skip the Build Kit and download the EXE above.
