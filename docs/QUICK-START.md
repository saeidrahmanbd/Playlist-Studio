# Playlist Studio — Quick Start

You only need the EXE. **You do not need the Build Kit.**

## Open the program

1. [Download Playlist Studio 5.0](https://github.com/saeidrahmanbd/Playlist-Studio/releases/download/v5.0.0/Playlist-Studio-5.0.exe).
2. Open your Downloads folder.
3. Double-click `Playlist-Studio-5.0.exe`.
4. Wait a few seconds for the first launch.

There is no installer, and you do not need to install Python or VLC separately.

## Open your playlist

- Use **Open** to select an M3U or M3U8 file.
- Or drag the playlist file onto the Playlist Studio window.
- Or choose **Import URL** to download a playlist from a link.

## Edit and save

1. Select a category and channel.
2. Make the changes you need.
3. Click **Save** to overwrite the current file, or **Save As** to create a separate copy.

**Tip:** If you import a playlist into a non-empty list, choose **Append** to add its channels or **Replace** to use the imported list instead.

## Test channels

Select a channel and use the built-in player. To check many links, click **Scan**. You can scan the whole playlist, the current category or the current view, then export the results to Excel.

## If something goes wrong

- **The app takes a while to open:** the first launch can take a few seconds.
- **Windows shows SmartScreen:** verify that you downloaded the EXE from the official release page. If it is the official file, select **More info → Run anyway**.
- **The app closes unexpectedly:** follow the recovery prompt when you reopen it.
- **Need the advanced options?** Open **Settings** for themes, player options, Xtream/Stalker settings and GitHub Integration.
