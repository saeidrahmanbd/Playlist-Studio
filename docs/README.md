## What Playlist Studio supports

- M3U/M3U8 files and URLs
- XMLTV EPG from URLs and local XML/GZ/XZ/ZIP files
- EPG coverage, channel matching statuses, Now / Next and manual corrections
- Channel and category editing, logos, stream URLs and metadata
- Stream scanning, persistent Good / Bad / Review verdicts and built-in playback
- Xtream Codes and Stalker Portal / MAC connections
- Saving, backups, autosave and recovery
- Windows portable EXE with VLC playback engine bundled
