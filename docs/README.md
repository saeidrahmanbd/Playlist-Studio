# Playlist Studio — Help and Documentation

**Current release: [Playlist Studio 5.1](https://github.com/saeidrahmanbd/Playlist-Studio/releases/tag/v5.1)**

Playlist Studio is a portable Windows M3U/M3U8 playlist manager and editor with XMLTV EPG tools, stream diagnostics and built-in playback.

## Start here

1. **[Download Playlist Studio 5.1](https://github.com/saeidrahmanbd/Playlist-Studio/releases/download/v5.1/Playlist-Studio-5.1.exe)** — portable Windows application.
2. **[Quick Start](QUICK-START.md)** — open, edit, scan and save a playlist.
3. **[Frequently Asked Questions](FAQ.md)** — formats, XMLTV EPG, stream scanning, provider imports and troubleshooting.
4. **[User Guide](PLAYLIST-STUDIO-5.0.md)** — detailed workflows and feature reference. Some screenshots or labels may reflect the earlier 5.0 interface.

## Feature reference

- M3U/M3U8 playlist files and URLs
- XMLTV EPG from URLs and local XML/GZ/XZ/ZIP files
- Programme coverage, channel matching statuses, Now / Next and manual corrections
- Channel/category editing, logos, stream URLs and metadata
- Stream scanning with diagnostic statuses and persistent Good / Bad / Review verdicts
- Built-in playback
- Xtream Codes and Stalker Portal / MAC import workflows
- Saving, backups and recovery
- Portable Windows EXE with bundled playback engine
