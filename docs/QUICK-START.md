# Playlist Studio — Quick Start (v5.1)

You only need the portable EXE. **You do not need the Build Kit.**

## Open the program

1. [Download Playlist Studio 5.1](https://github.com/saeidrahmanbd/Playlist-Studio/releases/download/v5.1/Playlist-Studio-5.1.exe).
2. Open your Downloads folder.
3. Double-click `Playlist-Studio-5.1.exe`.
4. Allow a few seconds for the first launch while the single-file app unpacks.

There is no installer. Python and VLC do not need to be installed separately to run the portable application.

## Open a playlist

- Use **Open** to select an M3U or M3U8 file.
- Drag a playlist file onto the Playlist Studio window.
- Choose **Import URL** to download a playlist from a link.
- Use the Xtream Codes or MAC / Stalker connection options in Settings when you have authorized provider details.

If you import into a non-empty playlist, choose **Append** to add channels or **Replace** to use the imported list instead.

## Edit and save

1. Select a category and channel.
2. Make your changes to names, groups, stream URLs, logos, EPG IDs or other metadata.
3. Click **Save** to overwrite the current playlist, or **Save As** to create a separate copy.

Use Undo / Redo to reverse recent edits. Playlist Studio also creates backups before overwriting and keeps recovery data for unsaved work.

## Work with EPG

Open **Settings > EPG centre** (or the EPG button) to load XMLTV guides from web addresses or local XML, GZ, XZ and ZIP files. Multiple guide sources can be loaded together. Review channel guide statuses, coverage and Now / Next, and edit IDs or metadata only after reviewing the proposed changes. Manual EPG corrections can be managed in Settings.

## Scan and play channels

Select a channel to test it in the built-in VLC player. Use **Scan** to check all channels, the selected category or the current view. Scan results distinguish Dead from Unreachable, Restricted, Stale, Unavailable, Unverified and Error. Timeouts and blocked requests are not automatically marked Dead. Your Good / Bad / Review verdicts and notes are kept between sessions.

## If something goes wrong

- **The app takes a while to open:** the first launch can take a few seconds because the single-file EXE unpacks itself.
- **Windows SmartScreen appears:** verify that you downloaded the EXE from the official v5.1 release. If so, choose **More info → Run anyway**.
- **A scan says Unreachable or Restricted:** this is not the same as a confirmed Dead stream; network restrictions and provider blocking can affect checks.
- **The app closes unexpectedly:** follow the recovery prompt when you reopen it.
- **Need advanced options?** Open Settings for General, Themes, Player, Xtream / Stalker, GitHub Integration, backups and About.
