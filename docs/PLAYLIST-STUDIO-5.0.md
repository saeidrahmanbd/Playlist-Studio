# 🖥️ Playlist Studio 5.0

**Windows Playlist Manager, Editor & Player**

Playlist Studio 5.0 is a general-purpose Windows application for managing, editing, testing, and playing M3U/M3U8 playlists and connecting to compatible IPTV services.

## Supported Sources and Tools

- M3U / M3U8 playlists
- Xtream Codes
- Stalker Portal / MAC
- EPG and channel metadata management
- Built-in playback and stream status scanning

## Key Features

- Import playlists from local files or URLs
- Organize channels and categories
- Edit channel names, IDs, channel numbers, logos, EPG data, and stream URLs
- Select multiple channels and categories
- Find duplicate channels and streams
- Test streams with built-in playback and scanning tools
- Save or Save As
- GitHub integration and multiple interface themes
